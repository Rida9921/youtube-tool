YouTube Tool

A small desktop utility that lets one person manage their own YouTube channel: publish videos, schedule releases, read statistics and reply to comments.

What it does

PublishUpload a video file with title, description, tags and category.
ScheduleSet a release date and let the video go public at that time.
StatisticsList recent videos with views, likes and comment counts.
CommentsRead new comments, reply, and moderate them.

How it works

The tool is a single command-line program that runs on the owner's own computer. It connects to the official YouTube Data API v3 using OAuth 2.0, after the account owner has explicitly granted access on Google's consent screen.

There is no server, no account system, no database and no analytics. The authorization token is stored in a local file on the same computer (token.json) and can be deleted at any time.

The tool acts only on the channel of the person who authorized it, and only when that person runs a command. Nothing happens in the background.

Data & privacy

The tool requests a single permission: https://www.googleapis.com/auth/youtube, which allows it to manage the authorized channel on the user's behalf.

Read the full Privacy Policy for details on what is accessed, where it is stored, and how to revoke access.
