Privacy Policy

YouTube Tool — last updated 18 November 2026

This policy explains what information YouTube Tool (“the tool”) accesses through Google APIs, how that information is used, where it is stored, and how you can revoke access.

The tool is a private, non-commercial desktop program operated by a single channel owner. It has no server, no user database and no third-party analytics.

1. Google account data accessed

When you authorize the tool, Google asks for one permission:

  • https://www.googleapis.com/auth/youtube — manage your YouTube account

With this permission, and only while you run a command, the tool can read or change:

DataPurpose
Channel name, ID and public statisticsShow which channel is connected
Your videos: title, description, tags, privacy status, view/like/comment countsList and update your own videos
Video files you explicitly point the tool toUpload them to your channel
Comments and replies on your videosRead, reply to and moderate them

The tool does not access your Gmail, Drive, Calendar, contacts, subscribers' personal data, or any channel you have not authorized.

2. How the data is used

Data is used exclusively to perform the action you requested from the command line — for example uploading a video you selected, or printing the view count of your own videos. No data is used for advertising, profiling, model training, or any purpose other than the requested operation.

3. Storage

Everything stays on your computer.

The only persistent data is an OAuth refresh token, saved in the plain file token.json next to the program. It is used to avoid asking you to sign in again. It is never transmitted anywhere except to Google's own OAuth endpoint. Video metadata retrieved from the API is printed to the terminal and not stored.

4. Sharing and disclosure

No data is sold, rented, shared, transferred or disclosed to any third party. There is no advertising network, no analytics service, no crash reporting service and no remote logging.

Google API Services User Data Policy. YouTube Tool's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. Retention and deletion

  • The refresh token is kept until you delete it.
  • To delete it: remove the file token.json from the program folder.
  • To revoke the tool's access to your Google account: open myaccount.google.com/permissions, select “YouTube Tool” and choose “Remove access”.
  • Revoking access invalidates the token immediately; the tool can no longer read or modify anything.

6. Security

The tool runs locally under your own Windows user account. The token file is protected by your operating system's file permissions; it should not be copied, shared or committed to a public repository. The client secret is stored in a local configuration file and is never displayed.

7. Children

The tool is not directed to children and is not intended for use by anyone under 13.

8. Changes

If this policy changes, the “last updated” date above will change. Material changes will be reflected on this page before the tool is used again.
